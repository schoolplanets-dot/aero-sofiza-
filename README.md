# Аэро-СофИзА · веб-приложение с геокартой и GPS

Это учебная диспетчеризация техобслуживания ВС (Школа №338), собранная из исходного файла `Админавтотрап_ОТО.html`. В неё добавлены карта по геоданным QGIS (полигон ВДНХ, стоянки мс-01…мс-10) и синхронизация с GPS. Интерфейс и структура исходного кода сохранены. Все дополнения подключаются отдельными блоками поверх существующих функций.

## Быстрый запуск

```bash
npm install
npm start            # http://localhost:3000
```

Переменные окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | 3000 | порт HTTP-сервера |
| `SCALE` | 1 | ускорение модельного времени (1 — реальное время, нужно для GPS) |
| `SIM` | 1 | серверный имитатор потока заявок; `SIM=0` отключает его |
| `TRACK_KEY` | пусто | ключ для приёма координат трекеров на `/api/track` |
| `DATABASE_URL` | — | MySQL-совместимая база данных для постоянного хранения состояния и чата (на опубликованном сайте задаётся платформой) |
| `DATA_DIR` | `./data` | где хранить состояние без базы данных (`oto-store.json`, `chat-history.json`) |

**GPS в браузере работает только через HTTPS** (или на `localhost`). Для работы с телефона разместите сервер за HTTPS-прокси (nginx/Caddy) или на любом хостинге с TLS.

Файл `public/index.html` можно открыть и без сервера. В этом случае программа работает автономно: состояние хранится в браузере, а GPS доступен, если страница открыта по https или как локальный файл в браузере, который это разрешает.

## Режимы

- `/` или `?mode=oto` открывает панель диспетчера ОТО. Карта OtoMap наложена на подложку: кнопка «◧» меняет подложку, «⌖» включает GPS и режим следования. Кнопка «← Исходная программа» переключает на исходный интерфейс, и выбор запоминается.
- `?mode=orig` открывает исходную программу. Под оперативной схемой появился фрейм **«Геокарта · учебный полигон»**: подложка OSM, спутник или тёмная; зоны и ВС из QGIS; маршрут автотрапа по реальным проездам; ваше положение по GPS.
- `?api=local` — автономный режим без сервера, данные хранятся в браузере.

Учебные входы: начальник смены `SM-01` / PIN `2468`; инженеры `AG-01` / `3381`, `AG-02` / `4292` и далее (PIN = первые 4 цифры от 3381 + 911·(n−1)).

## Как работает синхронизация с GPS

1. Браузер получает координаты через `navigator.geolocation.watchPosition`.
2. Позиция показывается на карте вместе с кругом точности. Рядом выводится расстояние до ближайшей стоянки (например, «до мс-02: 10 м»).
3. Если вошёл инженер, его позиция отправляется на сервер (`source: browser-gps`). Имитатор перестаёт двигать этого инженера, и диспетчер видит реальное положение. Позиция привязывается к ближайшему узлу дорожного графа, если он не дальше 80–150 м.
4. Через WebSocket `/ws/gps` позиции сразу рассылаются всем открытым клиентам («коллеги онлайн»).
5. Координаты вне полигона локации отклоняются с кодом `OUT_OF_BOUNDS`.

### Внешние трекеры (транспорт, телефоны без браузера)

```
GET/POST /api/track?id=<id>&lat=<lat>&lon=<lon>&accuracy=<м>&speed=<м/с>&bearing=<°>&key=<TRACK_KEY>
```

`id` — идентификатор инженера (`AT-0001`…) или транспорта (`vehicle-01`, `vehicle-03`, `V-TRAP`…). Для OsmAnd или Traccar Client укажите URL:

```
https://ВАШ_ХОСТ/api/track?id=vehicle-03&lat={0}&lon={1}&accuracy={3}&speed={5}
```

## Структура

```
storage.js                постоянное хранилище: база данных (DATABASE_URL) или файлы
Dockerfile                образ для публикации
server.js                 сервер: REST /api/v1 (ядро ОТО из index.html), имитатор, /ws/chat, /ws/gps, /api/track, статика
public/index.html         приложение (исходный код + дополнения, Leaflet встроен)
public/geodata/*.geojson  исходные слои QGIS (подгружаются фреймом «Геокарта»)
public/manifest.webmanifest, sw.js, icons/   PWA: установка на телефон, кэш тайлов
tools/build_pack.py       генерация пакета локации VDNH-GEO из geojson + дорожной сети OSM
tools/assemble.py         сборка public/index.html из исходника и tools/src/*
tools/src/geo-oto.js      подложка и GPS для карты ОТО
tools/src/geo-orig.js     фрейм «Геокарта» для исходной программы
tools/src/geo.css         стили дополнений
```

## Что изменено в исходном коде

Изменения минимальные и точечные. Добавлены PWA-мета и Leaflet в `<head>`, а пакет локации `VDNH-GEO` стал пакетом по умолчанию. Имитатор теперь не трогает объекты с живыми GPS-координатами. При запуске через сервер приложение подключается к API (`OTO_API_URL`). Остальное подключено отдельными скриптами-обёртками (`renderMap`, `animateTransportSegment`, `OtoMap.prototype`); исходные функции не переписывались.
